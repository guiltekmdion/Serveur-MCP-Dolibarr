# 50 Cas d'Usage pour l'Agent Dolibarr MCP

Voici une liste de 50 actions concrètes que vous pouvez demander à votre agent IA connecté à Dolibarr via ce serveur MCP.

## 🤝 CRM & Ventes (1-10)
1. **Rechercher un client** : "Trouve les coordonnées de l'entreprise 'Acme Corp'."
2. **Créer un prospect** : "Crée un nouveau prospect nommé 'StartUp Nation' avec l'email contact@startup.fr."
3. **Mettre à jour un contact** : "Change le numéro de téléphone de Jean Dupont chez Acme Corp en 06 12 34 56 78."
4. **Lister les contacts** : "Donne-moi la liste de tous les contacts associés à l'entreprise 'Big Corp'."
5. **Créer une proposition** : "Prépare un devis pour 'Client A' pour 5 jours de formation à 800€/jour."
6. **Ajouter une ligne au devis** : "Ajoute 'Licence Logiciel' à 500€ au devis PROV123."
7. **Convertir en commande** : "Le client a accepté le devis PROV123, crée la commande correspondante."
8. **Vérifier une commande** : "Quel est le statut de la commande CMD999 ?"
9. **Lister les factures** : "Montre-moi toutes les factures impayées de 'Client B'."
10. **Créer une facture** : "Génère la facture pour la commande CMD999."

## 📦 Produits & Stock (11-20)
11. **Chercher un produit** : "Quel est le prix du produit 'Service Maintenance' ?"
12. **Vérifier le stock** : "Combien de 'Laptop X1' avons-nous en stock ?"

14. **Mettre à jour un prix** : "Augmente le prix du 'Service Maintenance' à 90€."
15. **Lister par entrepôt** : "Quels produits sont stockés dans l'entrepôt 'Paris' ?"
16. **Créer un entrepôt** : "Crée un nouvel entrepôt 'Lyon Sud'."
17. **Mouvement de stock** : "Ajoute 50 unités de 'Stylo Bleu' suite à la réception fournisseur."
18. **Historique stock** : "Qui a sorti du stock pour le produit 'Papier A4' la semaine dernière ?"
19. **Détails produit** : "Quelle est la TVA appliquée sur le produit 'Formation' ?"
20. **Supprimer un produit** : "Supprime le produit obsolète 'Ancien Catalogue'."
